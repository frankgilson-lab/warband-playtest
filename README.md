# Warband — playtest build

A temporary, self-contained build of **Warband**, a hex-map miniatures wargame prototype,
put here so people can try it without installing anything.

**Play it: https://frankgilson-lab.github.io/warband-playtest/**

Two players, one screen, about twenty minutes. Everything runs in your browser — nothing is
sent anywhere, nothing is stored, no account needed.

## What it is

You draft your warband from shared packs **with the battlefield already visible**, so
composition is a decision about terrain rather than a deckbuilding exercise done in the dark.
When a unit dies it permanently reshapes the hex it fell on — a wood becomes a graveyard, a
ruin becomes rubble — so the ground you fought over is different for the rest of the match.
That mechanic is called Last Stand.

## Status

This repository is a **build artifact, not the source of truth**, and it is temporary — it
exists to gather playtest notes and will be taken down once it has. Development happens
elsewhere. `index.html` is generated by inlining the game's `config.js`, `core.js` and
`engine.js` into a single page; edit those upstream, not this file.

Hotseat only. Networked play exists in the engine but is switched off. There is no AI
opponent yet, so you need a second human.

Balance has been simulated across tens of thousands of games. Fun has been tested by nobody,
which is the entire point of this build.
