Shadow-Box — an experimental Warband playtest

A different look and a different set of interaction ideas for Warband, built on the canonical rules engine. The engine decides every legality, forecast and result; this page only draws them and routes your clicks.

  • One human against the sparring bot. You play Company A; the engine's bot plays Company B. There is no hotseat and no second human here.
  • Desktop only, for now. It has no mobile layout and no accessibility parity with the established playtest — it is a pointer-driven 1920×1080 canvas that scales, so small screens shrink the text rather than reflowing it.
  • This is not Warband Live. The streamer-versus-audience game is a separate prototype and is not part of this page.
  • Picks preview before they commit. Choosing shows you the outcome and a second action takes it. That is an idea under test here, not how the established playtest behaves.

The established playtest remains at frankgilson-lab.github.io/warband-playtest — go there for the current, supported build.
